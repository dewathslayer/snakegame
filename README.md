🐍 Snake Game

A classic Snake Game built in Python using the Turtle graphics library.
Eat the food, grow your snake, and try not to crash into the walls or yourself!

🎮 Game Overview

This is a simple yet fun snake game inspired by the classic Nokia version.
The project was built as part of Dr. Angela Yu’s 100 Days of Code: The Complete Python Pro Bootcamp course on Udemy.

✨ Features

✅ Smooth snake movement using keyboard controls

✅ Food appears randomly on the screen

✅ Score increases every time the snake eats food

✅ “Game Over” message appears when snake collides with wall or itself

✅ Simple and beginner-friendly code structure

🧠 Concepts Used

Object-Oriented Programming (OOP)

Event-driven programming using the turtle module

Collision detection

Score tracking and display

Screen update control using time.sleep() and Screen.update()
